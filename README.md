# SkillsTrack Learner Support Portal

## About the Project

The SkillsTrack Learner Support Portal is a website that will help learners manage their school work and support sessions in one place.

At the moment, SkillsTrack Training Centre uses different documents and messages to keep track of learner tasks, goals, support bookings and progress. This can make it hard for learners to know what they still need to do and for assessors to see which learners need help.

This project will bring this information together into one system.

## Problem

Learners currently use different places to keep track of their tasks and support sessions. Assessors also have to check different documents and messages to see learner progress.

This can cause information to be missed and makes it harder to keep track of outstanding work.

The portal will make it easier for learners to manage their work and for assessors to see learner activity.

## What the System Will Do

Learners will be able to:

* Create an account and log in.
* View their own information.
* Add new learning tasks.
* View their tasks.
* Edit tasks.
* Delete tasks.
* Mark tasks as completed.
* Search, filter or sort their tasks.
* Book a support session.
* View their progress.
* Print a progress summary.
* Use learning resources.
* Play a small coding game.

Assessors or administrators will be able to view support bookings and relevant learner activity.

## Firebase

Firebase Realtime Database will be used to save and get information from the system.

The main sections of the database will be:

```text
users
tasks
bookings
scores
resources
```

For example, tasks will contain information such as the task title, category, due date, priority and whether the task has been completed.

## Security

The system will use Firebase Authentication for passwords and login details.

Passwords will not be stored in the database or cookies.

Users should only be able to access the information that they are allowed to see.

User information will also be checked before it is saved to Firebase.

Private keys, passwords and other sensitive files will not be uploaded to GitHub.
