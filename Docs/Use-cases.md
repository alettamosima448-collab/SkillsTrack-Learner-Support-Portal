# Learner Support Portal - Use Cases

## USE CASE DEFINATION'

A use case explains how a learner will use the Learner Support Portal to complete a task.

## Use Case 1: Manage Learning Tasks

**User:** Learner

**Action:** The learner opens the learning tasks section and views or manages their tasks.

**Result:** The learner can keep track of their learning work.

## Use Case 2: Book Learner Support

**User:** Learner

**Action:** The learner opens the support section and makes a support booking.

**Result:** The learner can access the support they need.

## Use Case 3: View Support Bookings

**User:** Learner

**Action:** The learner opens their support bookings.

**Result:** The learner can see their booking information.

## Use Case 4: View Learning Progress

**User:** Learner

**Action:** The learner opens the progress section.

**Result:** The learner can see their learning progress.

## Use Case Summary

The main use cases allow learners to:

- Manage learning tasks.
- Book learner support.
- View support bookings.
- View learning progress.

These use cases help make the Learner Support Portal useful and easy for learners to use.
