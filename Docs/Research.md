# Research 



### 1. JavaScript

JavaScript will be used to make the portal interactive. I will use it for the task manager, forms, buttons, calculations and displaying information on the page.

I will also use arrays, functions, loops, conditions and methods such as `map()`, `filter()` and `reduce()` because these are required in the project.

### 2. Firebase

Firebase Realtime Database will be used to store the information for the portal. Firebase stores the data as JSON and can keep the data updated between connected applications.

For this project I plan to store:

* Users
* Tasks
* Support bookings
* Game scores
* Learning resources

Each task will have a `userId` so that I can identify which learner the task belongs to.

### 3. Firebase REST API

I researched the Firebase REST API because it will be used to communicate with the database.

The main methods are:

* **GET** – read data
* **POST** – add new data
* **PUT** – replace data
* **PATCH** – update part of the data
* **DELETE** – remove data

Firebase REST requests use the database URL with `.json` added to the end.

### 4. Firebase Security

The database needs to be protected so that users cannot access information that does not belong to them. Firebase Security Rules can control who is allowed to read and write data. REST requests can also be authenticated when rules require it.

### 5. GitHub

GitHub will be used to keep the project files and track changes. I will use branches, commits and pull requests so that each team member can show their contribution.

### 6. Conclusion

The research helped me understand how JavaScript, Firebase and GitHub will work together. JavaScript will control the website, Firebase will store the project data, and GitHub will help with version control and teamwork.
