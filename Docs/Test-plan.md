# Test Plan 

## Purpose

The purpose of testing is to make sure the basic SkillsTrack portal works correctly.

## What I Will Test

* Website navigation
* Forms
* Buttons
* Adding tasks
* Completing tasks
* Search and filter
* Progress calculation
* Cookie preference
* Firebase connection

## Test Cases

| Test              | Expected Result           |
| ----------------- | ------------------------- |
| Open website      | Page loads correctly      |
| Add a task        | Task appears              |
| Complete a task   | Task changes to completed |
| Search for a task | Correct task is shown     |
| Check progress    | Progress updates          |
| Change theme      | Preference is saved       |
| Submit empty form | Error message appears     |
| Test Firebase     | Connection works          |

## Bugs Found

I will record at least 3 problems during testing.

For each problem I will write:

* What went wrong
* How I found it
* How I fixed it
* Test the fix again

## Testing Tools

I will use the browser, developer tools, console and Firebase console.

## Goal

By the end of Month 1, the basic portal should work and the main problems found during testing should be fixed.
