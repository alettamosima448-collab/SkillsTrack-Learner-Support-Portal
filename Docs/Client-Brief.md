# Client Brief

## Client

SkillsTrack Training Centre

## Project

Learner Support Portal

## About the Client

SkillsTrack Training Centre provides short occupational programmes for learners.

The centre currently uses different documents and messages to keep track of learner goals, tasks, support bookings and progress. This makes it difficult to keep all the information in one place.

## The Problem

Learners do not have one system where they can manage their learning tasks and support bookings. They have to use different documents or messages, which can make it easy to miss tasks or forget about important information.

Assessors also find it difficult to see what work learners still need to complete, which learners need support and how much progress they are making.

## What the Client Needs

The client needs a website where learners can manage their learning activities in one place.

The system should allow learners to:

* Register and log in.
* Manage their own learning tasks.
* Create, edit and delete tasks.
* Mark tasks as completed.
* Book support sessions.
* View their progress.
* Use learning resources.
* Play a small coding game.
* Print a progress summary.

The system should also allow assessors or administrators to view support bookings and relevant learner activity.

## Dashboard

The dashboard should give learners a quick view of their work.

It should show:

* The total number of tasks.
* Completed tasks.
* Outstanding tasks.
* Their calculated progress.

## Task Manager

The task manager will allow learners to create and manage their learning tasks.

A task can include:

* Title.
* Category.
* Due date.
* Priority.
* Completed status.
* Date created.

Learners should be able to add, view, change and delete their tasks.

## Support Sessions

Learners should be able to book a support session through the portal.

The booking form should include:

* Topic.
* Preferred date.
* Notes.

The system should check that the information is correct before saving the booking and should show the user whether the booking was successful.

## Search and Filtering

The portal should include a way for learners to search, filter or sort their tasks.

This will make it easier to find specific tasks and see which work needs attention.

## Learning Resources

The portal can provide learning resources for learners.

These resources can include a title, type, link and description.

## Coding Game

The system will include a small coding game that learners can use to practise basic programming concepts.

The game will be made using an approved JavaScript framework or library.

## Technologies

The project will use:

* HTML5
* CSS3
* JavaScript
* Firebase Realtime Database
* Firebase Authentication
* Firebase REST API
* An approved JavaScript framework or library
* Git and GitHub

## Firebase

Firebase will be used to store the information used by the portal.

The planned sections include:

```text
users/{uid}
tasks/{taskId}
bookings/{bookingId}
scores/{scoreId}
resources/{resourceId}
```

## Security

The system must keep learner information safe.

Passwords will be handled by Firebase Authentication and will not be stored in the database or cookies.

Users should only be able to access information that they are allowed to see.

Information entered by users should also be checked before it is saved.

Private passwords, credentials and service-account files must not be added to GitHub.

## Project Scope

The main focus of the project is to build the required Learner Support Portal.

The project will cover:

* Registration and login.
* Learner dashboard.
* Task management.
* Support bookings.
* Progress calculations.
* Search, filtering or sorting.
* Learning resources.
* Coding game.
* Firebase.
* REST API.
* Testing and debugging.

## Expected Result

The finished system should give learners one place to manage their learning tasks, support bookings and progress.

It should also make it easier for assessors to see learner activity and support bookings.

The portal should be functional, easy to use and able to store and retrieve information correctly.
