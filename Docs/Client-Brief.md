# Learner Support Portal - Client Brief

## What is the Project?

The Learner Support Portal is a system that will help learners manage their learning and get the support they need.

## What Does the Client Need?

The client needs a portal that is easy for learners to use.

The portal should help learners with:

- Learning tasks
- Learner support
- Tracking learning progress

## Main Goal

The main goal is to create a simple and useful Learner Support Portal that helps learners manage their learning.

## Project Objectives

The project aims to:

- Make learning tasks easier to manage.
- Help learners access support.
- Allow learners to keep track of their progress.
- Make the system easy to understand and use.

## Who Will Use It?

The main users of the system are **learners**.

## What Will the Team Create?

The team will plan, design and develop the Learner Support Portal.

The project will also include:

- Requirements
- Research
- User Stories
- Use Cases
- Wireframes
- UI Designs
- Testing
- Project documentation

## Summary

The Learner Support Portal is designed to make learning easier for learners by helping them manage tasks, access support and track their progress.

The system should be simple, organised and easy to use.
