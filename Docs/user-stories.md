# User Stories

## 1. Create an Account

**As a learner, I want to create an account so that I can use the learner support portal.**

### Acceptance Criteria

* I can enter my name, email and password.
* The system checks that I filled in the required information.
* I can create my account if the information is correct.
* I get a message if there is a problem.

## 2. Login

**As a learner, I want to log in so that I can access my tasks and progress.**

### Acceptance Criteria

* I can enter my email and password.
* I can log in when my details are correct.
* I get an error message when my details are wrong.
* The system knows which user is logged in.

## 3. Add a Task

**As a learner, I want to add tasks so that I can keep track of my school work.**

### Acceptance Criteria

* I can enter a task title.
* I can choose a category and priority.
* I can add a due date.
* The task is saved.
* The new task appears on my task list.

## 4. Complete or Delete a Task

**As a learner, I want to update or delete my tasks so that I can keep my task list up to date.**

### Acceptance Criteria

* I can mark a task as completed.
* I can edit a task.
* I can delete a task.
* The system asks me to confirm before deleting.
* The task list updates after the change.

## 5. View My Progress

**As a learner, I want to see my progress so that I know how much work I have completed.**

### Acceptance Criteria

* I can see my total number of tasks.
* I can see how many tasks I have completed.
* I can see how many tasks are still outstanding.
* The system calculates my progress.
* The progress changes when I complete or update tasks.

## 6. Book a Support Session

**As a learner, I want to book a support session so that I can get help when I am struggling with something.**

### Acceptance Criteria

* I can enter the topic I need help with.
* I can choose a preferred date.
* I can add notes.
* I cannot submit the form if required information is missing.
* I get a message when my booking is submitted.

## 7. Search My Tasks

**As a learner, I want to search and filter my tasks so that I can find a task quickly.**

### Acceptance Criteria

* I can search for a task by its title.
* I can filter my tasks.
* The system only shows tasks that match my search or filter.
* The results update when I change the search or filter.

## 8. Save My Theme

**As a learner, I want to save my theme preference so that the portal remembers my choice.**

### Acceptance Criteria

* I can choose a theme.
* My choice is saved in a cookie.
* The theme is loaded when I return to the portal.
* No password or sensitive information is saved in the cookie.

## 9. Print My Progress

**As a learner, I want to print my progress so that I can have a copy of my results.**

### Acceptance Criteria

* I can open my progress summary.
* The summary shows my task information and progress.
* I can select a print button.
* The browser print window opens.
