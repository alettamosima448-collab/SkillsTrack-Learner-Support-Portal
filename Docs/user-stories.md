# Learner Support Portal - User Stories

## Introduction

User stories describe what learners need from the Learner Support Portal. They are written from the learner's point of view and explain what the learner wants to do and why.

## User Stories

### US01 - Manage Learning Tasks

**As a learner, I want to add and manage my learning tasks so that I can keep track of the work I need to complete.**

### US02 - View Learning Tasks

**As a learner, I want to view my learning tasks so that I know what work I need to do.**

### US03 - Complete Learning Tasks

**As a learner, I want to mark a learning task as completed so that I can keep track of the work I have finished.**

### US04 - Book Learner Support

**As a learner, I want to book learner support so that I can get help when I need it.**

### US05 - View Support Bookings

**As a learner, I want to view my support bookings so that I know when I am receiving support.**

### US06 - Track My Progress

**As a learner, I want to view my learning progress so that I can see how I am doing.**

### US07 - Update My Progress

**As a learner, I want my completed learning tasks to contribute to my progress so that my progress information stays up to date.**

### US08 - Easy Access to Support

**As a learner, I want the portal to be simple to use so that I can find the support and learning information I need easily.**

## Summary

The user stories focus on the main needs of learners:

- Managing learning tasks.
- Viewing and completing tasks.
- Booking learner support.
- Viewing support bookings.
- Tracking learning progress.
- Having an easy-to-use portal.
