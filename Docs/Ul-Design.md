# Learner Support Portal - UI Designs

## What is UI Design?

UI means **User Interface**.

It is what the user sees and uses when they open the Learner Support Portal.

The design should be simple, clear and easy for learners to understand.

## Main Design Goals

The UI should:

- Be easy to use.
- Be easy to understand.
- Have clear buttons and menus.
- Keep information organised.
- Make it easy for learners to find what they need.

## Main Portal Sections

The portal can have sections for:

- Learning Tasks
- Learner Support
- Support Bookings
- Learning Progress

## Design Ideas

### Home Page

The home page should give the learner an easy way to find the main sections of the portal.

### Learning Tasks

This section should allow learners to view and manage their learning tasks.

### Learner Support

This section should allow learners to access learner support.

### Support Bookings

This section should allow learners to view their support bookings.

### Learning Progress

This section should allow learners to view their learning progress.

## Simple Design Rules

The design should use:

- Clear headings
- Easy-to-read text
- Simple buttons
- Consistent layouts
- Easy navigation
- Enough space between sections

## Summary

The UI design should make the Learner Support Portal simple and comfortable for learners to use.

The learner should be able to quickly find learning tasks, support, bookings and progress.
